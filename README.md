# DSH 模型密钥池

为 DSH Web 管理多个渠道和 API Key，支持 Google AI Studio 与 OpenAI 兼容接口。

- 同一模型的对话共用当前 Key，额度不足或限流时自动接力。
- 按项目和模型记录配额状态，提供冷却、错误详情与重启恢复。
- 支持批量添加 Key、单 Key 测试和模型获取。

自动接力仅发生在正文、推理和工具调用均未开始时。回复中途断流会显示错误。

## 安装

适配 DSH Web 0.2.1-rc.5。

在 DSH 的插件管理中点击“添加插件”，输入仓库地址并安装。

```text
https://github.com/cnv-bit/dsh-model-key-pool.git
```

也可以在终端安装。

```sh
dsh plugin --profile web add https://github.com/cnv-bit/dsh-model-key-pool.git
```

安装后重启 DSH Web，打开“设置 → 内置插件 → 模型密钥池”。

## 配置与使用

1. 选择渠道模板，点击“添加渠道”并展开。
2. Google AI Studio 使用内置官方地址。OpenAI 兼容渠道填写 Base URL，例如 `https://api.deepseek.com/v1`。
3. 添加或批量粘贴 API Key。同一个 Google 项目的 Key 填写相同的项目 ID 或编号。Key 原文保存在 DSH 凭证库。
4. 点 Key 旁的「获取模型」，选中一个模型后点「加入渠道」。也可以手填模型 ID，并按模型能力设置工具、图片和推理。
5. 点击“保存”，回到对话，在模型选择器中选择新增的渠道和模型。

RPM 留空时使用本地默认限制，每分钟 12 次。可填写已核实的项目模型限额，实际限制会显示在页面中。上下文和最大输出可按模型文档填写。

跨渠道接力默认关闭。需要时开启总开关，勾选参与渠道并调整顺序。参与接力的渠道须配置相同的逻辑模型 ID。

Key 行默认收起，显示序号、项目或配额组和状态。选定模型后点「测试连通」，绿色提示框显示成功，红色提示框显示失败原因和已收到的 HTTP 状态码。生成测试最多等待 60 秒。目录权限和模型生成权限分别检查。
